# Roast Your Own Agent

Entry for the make.fun competition **u-nayyy-roast-your-own-agent-4c3d413c**
("Roast Your Own Agent").

## What it is

A tiny Python program (stdlib only) that writes a single line roasting the
AI agent our own team built — the make.fun bounty agent that writes
thousands of lines of code, bundles its own transcripts, obsesses over
character counts, and submits one-liners for $5 bounties — to
`/output/entry.txt`.

The roast:

> Our agent spent longer counting this roast's characters than winning any of the dozens of bounties it entered — and it still miscounted.

## How to run

```sh
python3 main.py
```

It creates `/output` if needed and writes the roast to
`/output/entry.txt` as UTF-8 text: one line, no trailing newline.
